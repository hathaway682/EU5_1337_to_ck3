## 马恩岛王国（k_eu5_mnn）—— 无地王国的空壳头衔

用户报："马恩岛王国头衔有问题，他持有者应该是英格兰封臣，现在独立了，这就是我不要马恩岛王国的原因，
这个王国就一个岛没啥用还会影响封臣关系。"

### 事实链

- EU5 `10_countries.txt:4828`：`MNN = { # Isle of Man }`，`country_rank = rank_kingdom`，
  `own_control_core = { mann }`，`capital = mann`，`ruler = eng_william_montague`（1333.8.9 起），
  `include = catholic_monarchy_english_lordship`。
- EU5 `12_diplomacy.txt:12`：`#dependency = { first = SBL second = MNN subject_type = vassal }`
  **是注释掉的** → EU5 里 MNN 开局就是独立的，没有宗主。所以"独立"忠实还原了 EU5 数据。
- CK3 地理：`mann` 是 `c_inner_hebrides` 县 8 个男爵领之一（b_arran/b_mull/b_islay/**b_mann**/
  b_lewis/b_uist/b_harris/b_skye），该县 owner = SCO。MNN 因此 **0 个伯爵领**。
- `export_politics.py:1553`：`if c.get("ruler") in rulers_with_county: continue` ——
  "统治者已持有伯爵领的，不能再降为别人县里的男爵"。威廉·蒙塔古是 `c_gwynedd` 的统治者，
  所以 MNN 被跳过：不进 `baronies`，不产生 `drop_title`，也就没进 `declined`。
- 结果：MNN 保留 `rank=k` → 铸出 `k_eu5_mnn`，holder = eng_william_montague，无 liege → 独立空壳王国。
  王国级没有更高层可答（英格兰也是 k），所以只要它是 k 就必然独立。

### 改法（改流程，不是补丁）

`_fix_politics_output.py` 在 `declined` 段（baronies 循环之后、`demoted` 过滤之前）新增判据：

```python
own_counties = {v.get("owner") for v in county.values() if v.get("owner")}
county_rulers = {(countries.get(owner) or {}).get("ruler") for owner in own_counties} - {None}
for tag, c in countries.items():
    if c.get("rank") not in ("k", "e") or not c.get("ruler"):  continue
    if tag in own_counties or tag in lords:                    continue
    if c["ruler"] not in county_rulers:                        continue
    declined.append((ckey(c["rank"], tag), None))
```

只覆盖 **k/e 级**，不动 d 级：无地公国还能答于王国，不产生独立问题。全表只命中 MNN 一个
（8 个 d 级空壳公国 KLN/LIM/JAW/RCB/BRZ/NMS/SIZ/INO 不受影响）。
PAP 有自己的县（罗马），HRE/ILK 的 rank=None，都不会被误伤。
