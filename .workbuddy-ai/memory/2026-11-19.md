- `map_data/adjacencies.csv` 新增 37 行 `sea` 类型连接，把地图左右边缘的 62 个
  `eu5_map_edge_sea` 海域（`common/province_terrain/zz_eu5_map_edge_terrain.txt`）
  按纬度配对，跨地图接缝连成一圈。
- 配对规则：按左右边缘列（x=0 / x=16383）上各省的 y 区间重叠量取最大，双向各求一次再取并集，
  保证 62 个边缘海域全部覆盖、无遗漏。

  x 直接用像素 x。已用原版 CK3 数据与 mod 内既有条目双重验证。
- 新增行沿用文件里既有两条接缝行（Kitagnaq / Qawalangin）的写法：Type=`sea`，Through=To 省 id。
- 文件保持 CRLF、无 BOM，终止行 `-1;-1;;-1;-1;-1;-1;-1;` 仍在末尾。

## 消除接缝连接在地图上画出的虚线

- CK3 会把 `sea` 连接的 `start_x/start_y → stop_x/stop_y` 之间画成虚线；原来两端分别在地图左右边缘，
  于是整条线横穿全图。
- 处理：37 条接缝行的终点收到 `x=1`、y 与起点相同（起点 `x=0`），线段退化成边缘一个像素的点。
  坐标只影响画线与军队上/下船位置，不影响连接本身。
- 备选方案（未采用）：`common/defines/graphic/00_graphics.txt` 里覆盖
  `NMapIcon { STRAITS_VISIBLE_ZOOM_STEPS = { 99 99 } }` 可隐藏**全部**海峡虚线，但会影响原版岛屿间的海峡提示。
- 另外把原有两条陆地接缝行（Kitagnaq `18328;18324`、Qawalangin `18280;18281`）的坐标同样收成
  `0;y → 1;y`，消除它们横穿全图的虚线。

## 1337 开局按 EU5 宫廷语言设置宫廷语言

- 新增 `common/on_action/zz_eu5_court_language.txt`：挂 `on_game_start_after_lobby`
  （与 `zz_eu5_salt_merchants.txt` 同写法），调用 `eu5_start_court_language`。
- 新增 `common/scripted_effects/zz_eu5_court_language_effects.txt`：114 个 1337 年
  王国/帝国/霸权持有者，逐个 `set_court_language`（一行一条，带 `# 头衔` 注释）。
- 取值链（EU5 的宫廷语言 = 该国文化的语言）：
  1. 角色 ID 前缀（`boh_`、`tur_`…）→ EU5 国家标签 → `setup/countries` 的 `culture_definition`；
  2. 该 EU5 文化名找同名 CK3 文化（`X` / `X_culture`）→ 取它的 `language` pillar；
  3. 找不到则用该文化 EU5 语言（`*_dialect`）的上级语言（`common/languages` 的 `dialects` 块）
     去掉 `_language` 后缀再找 CK3 文化（例：poitevin→french、lesser_polish→polish）；
  4. 无 EU5 标签的角色（`mb_yuan_*`、摄政）→ 最高头衔首都省份文化的 `language`。
- 例：波希米亚（约翰，CK3 文化 french）→ czech → `language_czech_slovak`；
  奥斯曼（首都省份文化 greek）→ TUR/turkish → `language_turkic`。
- 未做：`learn_court_language_of`（用户只要求设宫廷语言，未加学语言）。

## 修正：宫廷语言数据源（重要）

- 之前错误地用了 `in_game/setup/countries/*.txt` 的 `culture_definition`（国家文化）当宫廷语言。
- **正确数据源：`game/main_menu/setup/1337/10_countries.txt`** 里各国块内的
  `court_language = <dialect>`（含 `templates/*.txt` 里 14 个模板的 court_language）。
  例：ENG 显式 `court_language = norman_dialect`（不是 english）。
- 用户口径：**只设 EU5 开局显式写了 court_language 的国家，其余交给 CK3 引擎**。
- 映射：EU5 dialect → 同名 CK3 文化 → 该文化的 `language` pillar
  （norman_dialect → norman → language_french；catalan_dialect → language_occitano_romance）。
  新世界语言回退 `eu5_language_<key>` pillar，再用辅助目录
  `Global_modern_map/.../gen_debug/_culture_classification.csv`（eu5_language→language 列）。
  `church_dialect`（latin_language 下）→ `language_latin`；`church_slavonic_language` → `language_slavonic`。
- 结果：`common/scripted_effects/zz_eu5_court_language_effects.txt` 从 114 条缩到 **27 条**，
  只保留有显式 court_language 的 1337 统治者；效果名 `eu5_set_court_language_effect`
  （on_action `zz_eu5_court_language.txt` 调用）。
