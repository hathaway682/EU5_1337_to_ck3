## 诊断：梅特克尔（c_metekel）为什么显示亚美尼亚教会（用户 2026-10-20 问，未改文件）

链条（两层）：
1. `faith = miaphysitism` **是对的**：EU5 `06_pops.txt` gilgel_beles 有三个 pop——
   gumuz/rebba 2.807、**agaw/miaphysite 4.515（最大）**、gonga/omo 3.931。
   `_apply_culture_by_pops.py` 按省最大 pop 写入 → 省 13935/13936 =
   `culture = agaw_culture / faith = miaphysitism`。EU5 原设即 Agaw 基督徒。
2. `rite = armenian_rite` **是 bug**：`_apply_christian_rites.py` 规则 3（一性论残余兜底）：
   c_metekel owner=GUM（type=pop，无 liturgical_language）→ 语言路径落空；
   文化兜底名单 ETHIOPIAN_CULT("amhara","tigrinya","tigre","gonga_culture") /
   NUBIAN_EGYPT_CULT("nubian",...) **都不含 agaw_culture** → 落 else 一律 armenian_rite。
   且判定用的是 EU5 **县文化 gumuz**，而 rite 落地粒度是**省**（省文化 agaw）——
   「按县判定、按省落地」老坑的又一次翻版。
3. 注意 mod 的 miaphysitism `main_rite = coptic_rite`，只有显式写 armenian_rite 才会显示
   亚美尼亚礼；`_apply_christian_rites.py` 后段只把 armenian_apostolic 归一回 miaphysitism，
   rite 不跟着改，于是留下 `miaphysitism + armenian_rite` 的怪组合。

误伤清单（116 个 armenian_rite 省中 9 个非亚美尼亚文化省）：
- agaw×3：13935/13936（metekel）+13898（bazin/b_tembesha）→ 该 ethiopian_rite
- nubian×3：13978/13981/13993（kordofan）→ 该 coptic_rite；**名单坑：EU5 文化 key 是
  `nuba`，脚本里写的是 `nubian`，永远匹配不上**
- syriac×2：5827（marash，县文化 armenian，可保留）、6066（raqqa/b_jabar）→ 该 antiochian_rite
- kurdish×2：3681（amadiya/b_baskale，现实亚美尼亚化边缘，可保留）

待办（未动手，等用户确认）：规则 3 改按省粒度 + ETHIOPIAN_CULT 加 agaw_culture +
NUBIAN_EGYPT_CULT 修 nuba + else 兜底改为不写 rite（回落 coptic_rite），重跑脚本。

## 术语纠正（用户 2026-10-20 01:38 强调，已写进 MEMORY.md）

  "县/省粒度"说法作废，统一说"男爵领粒度"。

  barony = 首府）。要改伯爵领显示什么教会，必须动首府男爵领条目。
- 已把 _apply_christian_rites.py 注释改成新术语（纯注释改动，重跑幂等无变化）。
