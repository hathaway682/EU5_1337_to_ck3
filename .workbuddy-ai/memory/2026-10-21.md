1. **`in_game/map_data/location_templates.txt`** —— 一行一个 location：
   ```
   anadyr_trail = { topography = flatland vegetation = sparse climate = arctic religion = chukchi_shamanism culture = chukchi_culture raw_material = wild_game}
   ```
   **20918 个 location 有 `religion` 标注**。
   注意：**走廊类（trail / river）常不写 religion**，例如
   `indigiir_trail = { topography = mountain_wasteland vegetation = forest climate = arctic}`。
2. **`in_game/map_data/definitions.txt`** —— EU5 province 构成：
   ```
   shoromba_province = { solomoydokh nagaradalaax kulun_olbut cibagalaax xonuu soboloox indigiir_trail orgulaax_trail yukaghyr_upplands3 }
   ```
   4149 个 province，覆盖 27418 个 location。
3. `06_pops.txt` 的 `define_pop` 是**实际人口**（可能多宗教混合），location_templates 是**标注**（单一）。
   → 有人口时按人口多数（用户既有口径）；无人口（空块 `xxx = { }`）时才用 templates。

```
1. 06_pops.txt 有 define_pop  -> 按人口多数宗教

3. 否则同 EU5 province 内其它有 religion 标注的 location 的多数
```
