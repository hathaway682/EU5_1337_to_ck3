# 2026-10-18 工作日志

## 家族复用分析（EU5 mod vs CK3 原版）

**任务**：分析 EU5 mod 中哪些家族可以直接复用 CK3 原版家族定义。

**关键发现**：
- mod 与 vanilla 用两套不同 ID 体系：
  - mod 在 `common/dynasties/zz_eu5_dynasties.txt` 里用**命名 key**（如 `borjigin_dynasty`），name 字段是 `xxx_dynasty` 或 `name_xxx`
  - vanilla 用**数字 ID**（如 `11100`），name 字段是 `dynn_XXX`
  - mod 角色文件用 `dynasty = borjigin_dynasty` 引用，vanilla 用 `dynasty = 11100`
- 所以"复用"= 把 mod 自定义的那份删掉、改用 vanilla 数字 ID 对应的同名家族（vanilla 自带 CoA/prefix/本地化）

**统计**：
- CK3 原版 dynasty 总数：4214
- mod dynasty 总数：1272
- 语义同名匹配：257 条
  - A 类（culture 完全一致，直接可复用）：50
  - B 类（mod culture 为空，复用 vanilla 补 culture）：52
  - C 类（culture 不一致，多为 mod 用细分文化 vs vanilla 用父类，仍可复用）：155
  - 多对多匹配：mod 多 key 对同 vanilla 11 条；vanilla 多 ID 对同 mod 22 条（需手工核对）

**产物**：
- `gen_debug/dynasty_reuse_analysis.csv` —— 全量分类表
- `gen_debug/dynasty_reuse_analysis.md` —— 可读报告（含三类明细 + 多对多核对表）

**C 类典型情况**：mod 用细分文化（picard/tuscan/gascon），vanilla 用父类（french/italian/occitan）。
这不算冲突——CK3 文化是分层的，vanilla 家族定义本身就覆盖整棵文化树。但有几条差异较大需注意：
- ahom：mod=tai_nua_culture vs vanilla=assamese
- ashina：mod=touhoku_culture vs vanilla=khazar
- bahri：mod=crimean vs vanilla=egyptian
- audley：mod=english vs vanilla=norman

**多对多需注意**：
- anjou：mod 有 anjou_dynasty / anjou_jerusalem_dynasty / valois_anjou_dynasty
- chauhan：mod 有 chauhan_dynasty / chauhan_jalore_dynasty / chauhan_patna_dynasty
- hohenzollern：mod 有 hohenzollern_brandenburg / hohenzollern / hohenzollern_nurnberg 三个 key
- courtenay / harcourt / beaumont / barcelona / ayyubid / hafsid / cardona / gabras / ibelin 等在 vanilla 也有多个 ID
