## 按 EU5 development 给 CK3 伯爵领加 change_development_level

- EU5 没有静态 development 字段，值由 `main_menu/setup/1337/14_development.txt` 的公式算出：
  `base(-2) + coastal(5×natural_harbor_suitability) + river(0.5×river_size) + road(2) + rank(city5/town2) + vegetation + climate + topography + region + area + province + unique_location`。
- 数据源：`in_game/map_data/location_templates.txt`（地形/植被/气候/港口）、`setup/1337/07_cities_and_buildings.txt`（rank）、`setup/1337/09_roads.txt`（road）、`map_data/ports.csv`（coastal）、`map_data/definitions.txt`（location→province→area→region）。
- **definitions.txt 解析坑**：① 有单行闭合块 `province = { loc loc }`，必须按 `{`/`}` 计数分别处理，否则栈错位；② 有些 province 名不带 `_province` 后缀（`swat`/`hazara`/`balor`/`hunza`），province 要取「area 的直接子块」而不是靠后缀。
- **river 从像素取**：`rivers.png` 是 P 模式 16 色索引图。实际只用到 4 个河流色，按「像素越少=河越大」反推：idx11(0,0,100)=5（尼罗/多瑙/莱茵）、idx15(24,206,0)=4（叶尼塞/伯朝拉）、idx5(0,150,255)=3（塞纳/底格里斯）、idx4(0,200,255)=1（泰晤士）。idx254=(255,0,128) 陆地、idx255=海洋。11275 个 location 有河。
- 聚合到 county：`_tier_province_map.csv` 的 province→barony→county，barony 名去掉 `b_` 即 EU5 location；county 取所属 EU5 province 内最高 development 的 location。11 个 barony 名带国别后缀（`_ser/_bul/_lka/_mor/_alg/_tun`）匹配不到，11 个 county 无 province（撒哈拉/亚马逊/北美），兜底用 barony location 自身值。最终 3819/3819 全覆盖。
- 用户口径：**负数截断为 0**；river 修正要求从像素补算。
- 写入 `history/provinces/00_generated_provinces.txt`，每个 county 的**首府 barony 的 province id 块**（CSV 里该 county 首次出现的 province），字段 `change_development_level = N`（round 取整）。共写 3819 块，0 个已有该字段。BOM+CRLF 保持，括号 21046/21046 平衡。
