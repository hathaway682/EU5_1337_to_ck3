## 删除除 h_china 外的生成器大洲霸权（19:35）

- 需求：「把除了 h_china 以外的生成器生成的大洲霸权都删了，下面的头衔回到最高帝国级」。
- 对象：`common/landed_titles/00_landed_titles.txt` 顶层 7 个 h_ 里删 6 个——`h_america` / `h_oceania` / `h_africa` / `h_asia` / `h_atlantic_ocean_continent` / `h_europe`，保留 `h_china`。
- 做法（脚本 `gen_debug/_drop_continent_hegemonies.py`，幂等）：删块头行、块尾 `}`、以及**块内 depth==1 的标量行（霸权自己的 color/capital）**，其余行整体左移一个 tab；其直属 e_ 自动成为顶层帝国。共提升 13 个帝国：e_north_america / e_south_america / e_australasia / e_pacific_islands / e_central_africa / e_east_africa / e_north_africa / e_southern_africa / e_north_asia / e_north_atlantic_ocean_sub_continent / e_south_atlantic_sub_continent / e_eastern_europe / e_western_europe。
- **坑：缩进时不能把 h_ 自己的 color/capital 一起左移**，否则文件顶层会冒出 12 行 `color = {..}` / `capital = c_xxx` 散行（第一次跑就踩了，靠删这 12 行修回）。判据：depth==1 且该行不含 `{` 的行直接删，不要缩进。
- 结果：顶层只剩 57 个 e_ + 13 个 k_ + 1 个 h_（h_china），无重名块，括号 57639/57639 平衡。
- 本地化：11 个 `localization/*/eu5_titles_l_*.yml` 各删 6 行 h_ 键显示名（BOM+CRLF，按原样写回）；`h_china` 的名称走原版本地化，本来就没有覆盖行。
- 生成器同步：`_rebuild_dejure_cu.py` 加 `KEEP_HEGEMONIES = {"h_china"}`，emit 时只输出该集合里的 h_，其余 h_ 的直属帝国并进顶层帝国列表——重跑不会再生成大洲霸权。
- 保留未动：`zz_vanilla_titulars.txt` 的 `h_roman_empire` / `h_eastern_roman_empire` / `h_dar_al_islam` / `h_india` / `h_kingdom_of_heaven`（原版 landless 空壳，不是生成器产物）。
- 编码：`00_landed_titles.txt` 是 UTF-8 无 BOM + LF（不是 CRLF），写回按 LF。
