## 伊斯兰县层手动覆盖：呼罗珊/库锡斯坦/戈尔甘什叶派 → 十二伊玛目派

用户要求：整个呼罗珊 region + 库锡斯坦 area + 戈尔甘 province 的什叶派，一律定为十二伊玛目派（imami）。

- 三个地理实体来自 EU5 `in_game/map_data/definitions.txt`（empire→region→area→province→locations 层级）：
  - khorasan_region（`asia`/`central_asia` 下）
  - quhestan_area（注意拼写是 **quhestan** 不是 quhistan，`middle_east`/`persia` 下）
  - gorgan_province（在 mazandaran_area 下）
- mapping.json 里 location 的层级字段：`kingdom`=region、`duchy`=area、`province`=province、`county`=location 名本身。
  因此覆盖集合 = `kingdom=='khorasan'` ∪ `duchy=='quhestan'` ∪ `province=='gorgan_province'`（land location）。
- 三个实体共 82 个县（khorasan 76 + quhestan 5 + gorgan 1，有重叠去重后），其中 **9 个 shia 县**：
  mashhad / wakhan / nishapur / bojnurd / torbat_e_jam / gonabad / gorgan / sighnan / esfarayen。
- 这 9 县的 owner 全是逊尼学派国家（JKR/KHT/SFR=shafii、KRT/GRG=maturidi、BKH=无），
  父信仰不匹配 → 之前全走地理传播，被错传成 **zayidi（宰德派）**。
- 修复：`eu5_export/_apply_islamic_geo_spread.py` 在确定性判定后、地理传播前，插入
  `IMAMI_OVERRIDE_COUNTIES` 手动覆盖（这三个实体内的 shia 县 → imami）。
- 结果：9 县全部 zayidi → imami；imami 县数 5 → 14，zayidi 11；花括号 21046/21046 平衡；脚本幂等。
