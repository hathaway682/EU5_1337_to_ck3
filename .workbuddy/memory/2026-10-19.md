## §2 按「CU 首府男爵领 → 整县染色」直接对非洲/东南亚 pagan

- **用户口径**（原话）："按照CU那个mod里的CK3宗教和我们mod里的EU5宗教的男爵领重合度对"；
  "CU那边按照伯爵领首府自动染色整个伯爵领算"。
- **关键点（上一轮搞错的地方）**：CU 的 province 块只写在**伯爵领首府男爵领**上。
  正确做法是**按男爵领名匹配**（b_xxx 唯一，21046 个无重名），CU 首府男爵领落到我们的哪个县，
  就把该 rite **整县染色**；**不是**按县名匹配（按县名只能对上 65/421 个非洲县，覆盖率极低）。
- **脚本**：`gen_debug/_apply_cu_barony_fill.py`（`_cu_barony_overlap.py` 是只读对照版）。
  只处理 `faith == pagan`，不投票、不外推、不兜底；`rite → faith` 用 `faith.main_rite` 反查，

## §4 圣地定义换成 CU 的数据

- **用户指令**："对了，你把我们的圣地改成他们的数据"（他们 = CrusaderUniversalis）。
- **文件**：`common/religion/holy_site_types/00_holy_site_types.txt`（我们 273 个 → CU 326 个，实际写入 **321** 个）。
  备份 `.bak_cuholy_20261019_182958`。`01_dynamic_holy_site_types.txt`（10 个 `site_of_*`）**没动**。
- **核心难点**：CU 的圣地 county/barony 用的是 **CU 自己的命名**，跟本 mod 的 EU5 派生命名对不上：
  `c_antiocheia`(我们 c_antakya)、`c_bianzhou`(c_kaifeng)、`b_kiev`(b_kyiv)、`b_makka`(b_mecca)、`b_roma`(b_bracciano)。
  326 个圣地里 **219 个 county 名在本 mod 不存在**，直接复制会全废。
- **换算规则**（`gen_debug/_apply_cu_holy_sites.py`）：
  1. CU 的 `barony` 在本 mod 存在 → 用它，county 取包含该 barony 的县（**313 个**走这条）
  2. 否则用本 mod 原圣地的 (county, barony)（**7 个**：bahrein/kiev/konugardr/mecca/rome/surgut/visoki，CU 拼写不同）
  3. 否则 CU 的 county 存在 → 保留 county、删 barony（1 个）
  4. 都不行 → **丢弃**（5 个：siffa/kusinagara/sagya/ava/sittaung，county 在本 mod 地图上不存在，且 0 个 faith 引用）
- **校验**：321 个圣地，county 无效 0、barony 无效 0；faith 引用的 270 个 key **全部有定义**（缺 0）。
  BOM 在 / 纯 CRLF 8075 / braces 1610:1610。
- **坑**：CU 的圣地文件里有**带连字符的 key**（`takht-i-sangin`、`takht-e_soleyman`、`ushi-darena`、`buru-sula`），
  块正则必须写成 `[A-Za-z0-9_\-]+`，否则会被当成 `sangin` 这类残名。
- **没动**：faith 里的 `holy_sites` / `eminent_holy_sites` 列表（哪些信仰认哪些圣地）仍是原来的，未换成 CU 的。
